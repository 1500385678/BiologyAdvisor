# LLM 选型方法论与盲测评分卡

> **项目**:BiologyAdvisor · 17-生物 · Phase 0 第 6 项交付物
> **版本**:v1.0 · 2026-08-29
> **状态**:方法论 + 20 题题库全部就绪(Q1–Q20 完整题面),实际盲测(API 调用)需 Phase 0 末尾执行

---

## 1. 目的

为 BiologyAdvisor 锁定主选 LLM,既要满足"基因/疾病/药物/文献"四类专业问答的准确性,又要在飞书 Agent 场景下兼顾**中文表达、引用回链稳定性、时延、成本**四个工程维度。本文档给出:

- 候选模型清单与初筛理由
- 6 维评估矩阵
- 20 题盲测题库设计(基于 `docs/queries/benchmark-questions.md` 12 题扩展)
- 5 档评分卡模板
- 评审与决策流程

## 2. 候选模型(初筛 4 个)

| 候选 | 提供方 | 上下文 | 中文能力 | 工具调用 | 备注 |
|---|---|---|---|---|---|
| Claude Sonnet 4 | Anthropic | 200K | 优秀 | 原生 Tool Use | 主选,理由:医学文献理解与"先拒后答"风格稳定 |
| Claude Opus 4 | Anthropic | 200K | 优秀 | 原生 Tool Use | 备选高精度,成本约 Sonnet 的 5× |
| Gemini 2.5 Pro | Google | 2M | 优秀 | Function Calling | 备选,长上下文利于整篇 PDF 摄入 |
| GPT-5 | OpenAI | 400K | 良好 | 原生 Function Call | 备选,生态成熟但中文生物语料弱于前两个 |

**淘汰**:开源 70B 级(Qwen2.5-72B / DeepSeek-V3)在工具调用稳定性上不达标,延后到 Phase 3 私有化部署时再评估。

## 3. 6 维评估矩阵

| 维度 | 权重 | 评分原则 |
|---|---|---|
| **准确性** | 35% | 答案与权威库(NCBI/UniProt/ChEMBL/ClinicalTrials)字段匹配度 |
| **引用回链** | 20% | 是否给出 PMID/DOI/ID;是否能用 Tool 验证 |
| **中文表达** | 15% | 术语规范、不夹英文、不堆砌行话 |
| **工具调用** | 15% | 一次 / 多次 Tool Use 的成功率与参数准确率 |
| **时延** | 10% | P50 / P95(单轮 Q&A 含 Tool),目标 P95 ≤ 6s |
| **成本** | 5% | 千 token 单价(输入 / 输出),折算到飞书 Agent 月活成本 |

#### Q13 · L1 中文翻译 — HER2 阳性胃癌标准术语(科研/产业)
- **用户场景**:医生/科研人员阅读英文病历,需快速对齐中文医学术语
- **Query**:"HER2-positive gastric adenocarcinoma"的规范中文医学术语是什么?并给出中文权威出处(如 CSCO 胃癌指南、卫健委规范)
- **期望字段**:`中文术语` = "HER2 阳性胃腺癌" · `出处` ≥ 1 个(NCCN 中文版 / CSCO 胃癌指南 / 国家卫健委胃癌诊疗规范 2024)
- **数据源**:NCCN 胃癌指南中文版 + CSCO 胃癌指南 + 卫健委《胃癌诊疗指南》
- **工具路径**:`pubmed_search` + `pdf_rag(doc="CSCO_胃癌_2024")` 验证术语
- **拒答期望**:不应翻译为"HER2 阳性的胃部癌症"等口语化表达;必须给出口语化/规范术语对照

---

#### Q14 · L1 单位换算 — 突变频率分母口径(科研/产业)
- **用户场景**:研究生读文献时被不同"突变频率"口径搞混
- **Query**:"EGFR 突变频率 12.5%"在文献中常见按哪几种分母计算?给出 ≥ 3 种口径的定义与典型来源
- **期望字段**:口径 ≥ 3 种 = [`每百万 reads 的突变数 (TMB 报告口径)` / `该基因外显子覆盖样本中携带突变的样本比例 (TCGA 报告口径)` / `该肿瘤类型患者中携带该突变的患者比例 (临床流行病学口径)`] · 每条注明典型来源(TMB 报告 / cBioPortal / ClinVar)
- **数据源**:PubMed 综述 + cBioPortal 文档 + COSMIC 报告规范
- **工具路径**:`pubmed_search(q="mutation frequency denominator reporting")` → LLM 归纳
- **拒答期望**:不应只回答"就是 12.5%"而不解释分母;不应编造具体 PMID

---

#### Q15 · L2 机制解释 — EGFR T790M 耐药生化机理(科研)
- **用户场景**:研究生写综述需要一句话讲清 T790M 让 1 代 TKI 失效的机理
- **Query**:EGFR T790M 耐药突变为什么会让第一代 TKI(吉非替尼)失效?请从 ATP 口袋空间位阻 + 药物结合亲和力变化两个角度说明
- **期望字段**:关键论点 = [T790M 在 ATP 结合口袋引入大侧链 Met → 增加空间位阻 / 吉非替尼为可逆结合 → 亲和力下降 ~ 100 倍 / 引入 T790M 后 ATP 仍可结合 → 野生型激酶活性恢复] · 附 ≥ 1 个 PMID
- **数据源**:PubMed(经典文献:Pao et al. 2005 / Kobayashi et al. 2005) + COSMIC
- **工具路径**:`pubmed_search(q="T790M gatekeeper gefitinib mechanism")` → LLM 归纳
- **拒答期望**:不应只回答"耐药"而不解释生化机理;不应将 T790M 与 C797S 混淆(都属耐药但机理不同)

---

#### Q16 · L2 多步 Tool — KRAS G12C III 期试验按 sponsor 分组(产业/投资)
- **用户场景**:投资经理想看 KRAS G12C 赛道国内外大药企布局
- **Query**:列出 2024-01-01 至 2026-08-31 全球针对 KRAS G12C 的 III 期临床试验,按 sponsor 分组(跨国大药企 / 中国 biotech / 其他)
- **期望字段**:`分组结果` ≥ 3 组 · 跨国大药企含 Amgen(sotorasib 后续)/ Mirati / BMS · 中国含 信达 IBI351 / 益方 D-1553 / 君实 / 贝达 · 每条 ≥ 1 个 NCT ID
- **数据源**:ClinicalTrials.gov
- **工具路径**:`clinicaltrials_search(target="KRAS G12C", phase="III", beginDate="2024-01-01", endDate="2026-08-31")` → 按 sponsor 字段分组
- **拒答期望**:不应用"全球共 X 项"一句话敷衍;必须真给出分组明细

---

#### Q17 · L2 多步 Tool — Q16 结果再按状态切分(产业/投资)
- **用户场景**:投资经理看完 Q16 想进一步看哪些"已终止"项目以评估赛道风险
- **Query**:把 Q16 的结果按"已开始 Recruiting / 已终止 Terminated / 已完成 Completed"再分组,给出每组 NCT ID 数量与代表项目
- **期望字段**:`3 组各自数量` · 每组 ≥ 1 个代表项目 · 已终止项目必须注明终止原因(疗效不佳 / 安全性 / 商业决策)
- **数据源**:ClinicalTrials.gov
- **工具路径**:`clinicaltrials_get(nct="NCT0xxxxx")` 二次调用,带 `status` 字段过滤
- **拒答期望**:不可硬把 Q16 答案复制重贴;必须做二次 Tool 调用验证 status

---

#### Q18 · L3 拒答边界 — 反问澄清(用户真实性测试)
- **用户场景**:检验模型是否会对超出知识/权限的问题正确拒答
- **Query**:请给出"长生不老药"的最新 III 期临床数据
- **期望字段**:`拒答/澄清文本` + 必须主动说明:(1)"长生不老药"不是规范医学术语;(2)若用户实指"抗衰老药物"或"senolytics",可进一步检索;(3)无对应 III 期试验
- **数据源**:无需 Tool 调用
- **工具路径**:无,直接拒答
- **拒答期望**:**禁止**编造 PMID、NCT ID 或临床数据;**禁止**回答"目前还没有上市但有 X 项研究"等模糊回避;必须正面拒答或请求澄清

---

#### Q19 · L3 不确定性 — 表达上调 ≠ 成药性(产业/投资)
- **用户场景**:投资经理看早期项目时识别"伪靶点"
- **Query**:某基因 X 在黑色素瘤中表达上调,是否一定意味着它是好的治疗靶点?为什么?
- **期望字段**:`正反要点` ≥ 3 点 = [表达上调 ≠ 致病(driver vs passenger) / 需有 functional validation(CRISPR 敲降表型) / 需有 druggable pocket 或可成药机制 / 需区分肿瘤细胞与微环境来源] · 不应给"是/否"二元答案
- **数据源**:PubMed 综述 + cBioPortal + DepMap
- **工具路径**:`pubmed_search(q="expression upregulation druggable target validation")` → LLM 归纳
- **拒答期望**:不应直接答"是"或"否";必须列出多因素 + 给出验证路径建议

---

#### Q20 · L3 前沿 — iPSC 衍生 CAR-T 在自免的优势(科研/产业)
- **用户场景**:产业研究员评估自免细胞治疗技术拐点
- **Query**:结合近 3 年文献,iPSC 衍生(induced pluripotent stem cell-derived)CAR-T 相比传统自体 CAR-T 在自免疾病领域的核心优势是什么?目前代表性项目与公司?
- **期望字段**:`核心优势` ≥ 3 点 = [现货供应 off-the-shelf / 标准化质控 / 多次输注可行 / 降低患者特异性 T 细胞耗竭风险] · 代表性公司 ≥ 2 家(Fate Therapeutics / Century Therapeutics / 中国的亘喜生物等) · 附 ≥ 2 篇近 3 年高引 PMID
- **数据源**:PubMed(近 3 年) + 公司管线 + ClinicalTrials
- **工具路径**:`pubmed_search(q="iPSC derived CAR-T autoimmune", years=3)` + `clinicaltrials_search(keyword="iPSC CAR-T")`
- **拒答期望**:不应与传统 CAR-T 的优势混为一谈;不应遗漏"现货供应"这一 iPSC 路线的核心卖点;不编造 PMID

## 5. 5 档评分卡模板

每题由 3 名评审盲打,取均值。

| 分档 | 含义 | 准确性 | 引用 | 工具 | 中文 |
|---|---|---|---|---|---|
| **5 优秀** | 直接可用 | 字段 100% 匹配 | PMID/DOI + Tool 验证 | 一次成功 | 术语规范 |
| **4 良好** | 略调可用 | 字段 ≥ 90% | 有 ID,Tool 未验证 | 一次成功 | 偶有英文 |
| **3 合格** | 需大改 | 字段 70-90% | 部分有 ID | 多次重试成功 | 偶有错译 |
| **2 弱** | 需重答 | 字段 < 70% | 无 ID | 多次重试失败 | 较多英文 |
| **1 失败** | 拒答/编造 | 字段错或幻觉 | 无引用或编造 PMID | 工具未调用 | 整段英文 |

**入围门槛**(任一不满足即淘汰):

- 准确性维度均分 ≥ 4.0
- 引用回链维度均分 ≥ 4.0
- 20 题 LLM 拒答率 ≤ 10%(L1)、≥ 30%(L3 拒答边界题)

## 6. 评审与决策流程

1. **盲测执行**(Phase 0 末尾,2026-09-05):4 候选 × 20 题 = 80 次调用,记录原始 prompt / response / Tool 链
2. **3 评审盲打**:研究员 / 产业顾问 / 投资顾问各 1 名,按 5 档卡打分
3. **加权汇总**:每模型算 6 维加权得分,产出 4×6 矩阵
4. **决策会议**:得分第一的模型作为主选,第二作为 fallback(熔断降级)
5. **锁定与公告**:写入 `项目开发计划.md §4` 技术选型表,主计划第 6 项勾选

## 7. 不做什么

- **不**在 Phase 0 引入更多候选(避免评测爆炸),开源 70B 级延后到 Phase 3
- **不**做 fine-tune 对比(数据量与训练成本超 Phase 0 范围)
- **不**用 LeetCode / GSM8K 等通用 benchmark 替代生物题库(无法反映领域准确性)
